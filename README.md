# Sonus-RS

Pure-Rust music-generation node for the [ApexOS](https://github.com/buckster123/ApexOS-RS)
colony — a lean Suno API (sunoapi.org) client + MCP plugin, drop-in
replacement for the Python hermes-sonus plugin. No venv, single-digit-MB RSS:
any old Pi becomes a composer.

The three senses: [Occipital-RS](https://github.com/buckster123/Occipital-RS)
(web) · [Imaginarium-RS](https://github.com/buckster123/Imaginarium-RS)
(vision) · **Sonus-RS** (sound).

Status: bootstrapped — see `BACKLOG.md` for the slice ledger and
`docs/hermes-parity.md` for the drop-in contract.
